How to Play & Safety Architecture

Game Objective

A digital city is under attack by corrupted files. Files are enemies marching toward the city wall. Route each file to the correct defense bunker before it arrives!

Controls

  • 1 - Documents (PDF, Word, Spreadsheets)
  • 2 - Images (Photos, Screenshots)
  • 3 - Videos (Clips, Recordings)
  • 4 - Code (Python, JS, Configs)
  • 5 - Archives (ZIP, TAR, 7Z)
  • 6 - Installers (Setups, Executables)
  • 7 - Quarantine (Duplicates, Temp, 0-byte logs)
  • 8 - Keep in Place (Leaves file untouched)
  • Space or Enter - Accept AI Suggestion
  • Tab / Shift+Tab - Cycle Targeted Enemy
  • P or Esc - Pause / Resume Game
  • C - Toggle Calm Mode (No timers, no damage)
  • M - Toggle Sound Effects
  • Z - Undo Last Run (When execution completes)

Safety Guarantees

  • No Permanent Deletion: "Quarantine" moves files to .taskocalypse_quarantine/ inside the selected folder. Nothing is permanently destroyed.
  • Dry-Run First: No files are modified on disk during gameplay. You inspect the full plan at the end and must explicitly confirm before execution.
  • Collision-Safe: Never overwrites existing files. If a filename collision occurs, a safe counter suffix like (1) is added.
  • Skipped Files are Untouched: Files that reach the wall unrouted take city health damage but produce zero disk actions.
  • 1-Click Undo: Every run writes an atomic journal. Click "Undo" or press Z to return every file to its exact origin.
